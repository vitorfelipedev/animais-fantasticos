# 🐾 Animais Fantásticos

O **Animais Fantásticos** é uma landing page interativa desenvolvida com **JavaScript**, **HTML** e **CSS**, criada para aplicar conceitos fundamentais de desenvolvimento frontend. O projeto reúne diversos componentes interativos, animações e integrações com APIs, proporcionando uma experiência moderna e responsiva.

Este projeto foi desenvolvido como parte dos meus estudos em JavaScript, explorando manipulação do DOM, modularização com ES Modules, consumo de APIs REST e criação de interfaces dinâmicas.

🌐 **Acesse o projeto:**  
https://vitorfelipedev.github.io/animais-fantasticos/

---

## ✨ Funcionalidades

- 🐺 Navegação por abas
- ❓ FAQ com efeito accordion
- 🧭 Menu responsivo com dropdown
- 🪟 Modal de login
- 🖼️ Slider de imagens
- 📈 Contadores animados
- 🧠 Tooltips interativos
- ✨ Animações durante o scroll
- ₿ Integração com API para cotação do Bitcoin
- 📱 Interface responsiva

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/vitorfelipedev/animais-fantasticos.git
```

### 2. Acesse a pasta do projeto

```bash
cd animais-fantasticos
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

O Webpack iniciará o ambiente de desenvolvimento e observará alterações automaticamente.
